* Distinction Bench: isolating abstraction
Most benchmarks are about translating between similar formats, or increasingly /tangled/ rules.
  
A simple idea: test *simple rules* in *many different representations*.

- /Abstraction/ :: the act of ignoring *irrelevant details* and *focusing on the relevant parts.*
  Can the model apply the same simple rules when only the encoding changes?
  
  
  : accuracy (Γ) + invariance drop across dialects (∆rep)


* Why Distinction Bench?
If a model can't stay consistent across equivalent encodings, you can’t trust it to:
- follow specs across formats
- generalize across UI / tools
- be audited (evals lie)
