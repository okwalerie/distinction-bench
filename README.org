#+title: Distinction Benchmark

This repository contains the Distinction Benchmark and the Laws of Form benchmark toolkit for evaluating LLM reasoning.

** Installation
#+begin_src bash
uv sync --group dev
#+end_src

for non-authoritative local visual development on ubuntu/debian:

#+begin_src bash
sudo apt-get update && sudo apt-get install -y libcairo2 libpango-1.0-0
uv sync --group dev --extra visual
uv run pytest -m requires_visual_runtime
#+end_src

local cairo/pango packages are useful for smoke tests, but their png bytes are
platform-dependent and are *not* the frozen hash authority. authoritative v1
verification builds =.github/visual-runtime/Containerfile= and runs the preflight,
11,600-cell replay, and marked visual tests exactly as specified in
=.github/workflows/ci.yml=. see =docs/visual-authority-runtime.md= for the pinned
runtime and local reproduction commands.

** Usage
#+begin_src python
from lofbench import simplify_string, canonical_string, generate_form_string

# Simplify a form
result, steps = simplify_string("(()())")
print(result)  # "void"

# Generate random forms
form = generate_form_string(min_depth=2, max_depth=4)
print(form)  # e.g. "((())(()))"

# Get canonical result
print(canonical_string("()()"))  # "()"
#+end_src

** Running Evaluations

Public runs use the release operator, which plans against the packaged frozen suite,
persists provider evidence before accounting, and is dry by default.

#+begin_src bash
uv run python -m dbench --help
#+end_src

Do not invoke Inspect directly for public release data.

** Laws of Form

Spencer-Brown's Laws of Form defines a minimal calculus with two axioms:

- *I1 (Calling)*: =()() → ()= — Adjacent marks condense to one
- *I2 (Crossing)*: =(()) → void= — Nested mark cancels to void (aka, not represented)

Every expression reduces to either =()= (marked) or =void= (unmarked).
